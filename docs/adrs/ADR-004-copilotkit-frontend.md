# ADR-004: CopilotKit for AI UI Integration

**Status:** Accepted
**Date:** 2025-12-28
**Deciders:** Architecture Team
**Technical Story:** FR19-FR22 (Copilot Interface Requirements)

## Context

The Agentic RAG platform requires a sophisticated AI-powered user interface with:

1. **Real-time agent state synchronization** - Users should see agent thinking/actions in real-time
2. **Generative UI** - Dynamic UI components generated by agents
3. **Human-in-the-loop (HITL)** - User approval workflows for critical decisions
4. **Frontend actions** - Ability for users to trigger agent behaviors from UI
5. **Chat interface** - Conversational interaction with the RAG system

The PRD specifies FR19-FR22 for copilot interface requirements:
- FR19: Chat sidebar interface
- FR20: Generative UI components
- FR21: Human-in-the-loop source validation
- FR22: Frontend actions

### Frontend Technology Landscape (2025)

| Framework | AI Integration | Protocol Support |
|-----------|---------------|------------------|
| CopilotKit | Native | AG-UI, MCP Client |
| Vercel AI SDK | Good | Custom streaming |
| LangChain.js | Limited | LangServe only |
| Custom React | Manual | Custom implementation |

## Decision

We adopt **CopilotKit** as the AI UI framework for the Next.js frontend.

### Key Capabilities

1. **AG-UI Protocol Native**: First-party implementation of Agent-UI protocol
2. **Generative UI (A2UI)**: Agents can emit UI widgets dynamically
3. **HITL Workflows**: Built-in patterns for approval/rejection flows
4. **Real-time Streaming**: SSE-based state synchronization
5. **React Hooks**: Modern hook-based API for all interactions

## Consequences

### Positive

- **Protocol Native**: AG-UI implementation without custom code
- **Rapid Development**: Pre-built components for common patterns
- **Real-time UX**: SSE streaming provides immediate feedback
- **Generative UI**: Agents can create custom UI dynamically
- **Modern API**: Hook-based patterns align with React best practices
- **MCP Client**: Built-in support for consuming MCP tools
- **Active Development**: Well-maintained with regular updates

### Negative

- **Vendor Dependency**: Tight coupling to CopilotKit library
- **API Evolution**: Hooks API has evolved (useCopilotAction --> useFrontendTool)
- **Styling Constraints**: CopilotKit components have their own styling
- **Learning Curve**: Team needs to learn CopilotKit-specific patterns
- **Bundle Size**: Adds to frontend bundle

### Neutral

- **Next.js Requirement**: CopilotKit works best with Next.js (already chosen)
- **TypeScript**: Requires TypeScript (already part of stack)
- **React 18+**: Requires React 18+ (already part of stack)

## Alternatives Considered

### 1. Vercel AI SDK Only

**Rejected because:**
- No native AG-UI protocol support
- Would require custom streaming implementation
- No built-in generative UI patterns
- HITL workflows need custom implementation
- Less feature-rich for agent UIs

### 2. LangChain.js / LangServe

**Rejected because:**
- Conflicts with Agno framework (backend)
- LangServe is Python-backend specific
- Limited frontend component library
- No AG-UI protocol support

### 3. Custom React Implementation

**Rejected because:**
- Significant development effort
- Would need to implement AG-UI from scratch
- SSE handling needs custom code
- Generative UI patterns need design
- Maintenance burden

### 4. Streamlit / Gradio

**Rejected because:**
- Python-only (no Next.js integration)
- Limited customization
- Not suitable for production applications
- Poor TypeScript support

### 5. AI Chat Libraries (react-ai-chat, etc.)

**Rejected because:**
- Chat-only, no agent state sync
- No protocol support
- No generative UI
- No HITL patterns

## Implementation Notes

### CopilotKit Provider Setup

```typescript
// frontend/src/providers/CopilotProvider.tsx
import { CopilotKit } from "@copilotkit/react-core";

export function CopilotProvider({ children }: { children: React.ReactNode }) {
  return (
    <CopilotKit
      runtimeUrl="/api/copilot"
      showDevConsole={process.env.NODE_ENV === "development"}
      transcribeAudioUrl="/api/copilot/transcribe"
      textToSpeechUrl="/api/copilot/tts"
    >
      {children}
    </CopilotKit>
  );
}
```

### Modern Hook Patterns

```typescript
// MODERN: useFrontendTool (replaces useCopilotAction with handler)
import { useFrontendTool } from "@copilotkit/react-core";

useFrontendTool({
  name: "validate_sources",
  description: "Approve or reject retrieved sources",
  parameters: z.object({
    sourceIds: z.array(z.string()),
    decision: z.enum(["approve", "reject"])
  }),
  handler: async ({ sourceIds, decision }) => {
    // Handle validation
  }
});

// MODERN: useHumanInTheLoop (replaces useCopilotAction with render)
import { useHumanInTheLoop } from "@copilotkit/react-core";

useHumanInTheLoop({
  name: "approve_action",
  description: "Get user approval for action",
  parameters: z.object({ action: z.string() }),
  renderAndWait: ({ action, resolve }) => (
    <ApprovalDialog action={action} onApprove={() => resolve("approved")} />
  )
});
```

### A2UI Widget Rendering

```typescript
// frontend/src/components/copilot/A2UIWidgetRenderer.tsx
type A2UIWidget =
  | { type: "card"; title: string; content: string }
  | { type: "table"; headers: string[]; rows: string[][] }
  | { type: "chart"; chartType: string; data: ChartData }
  | { type: "form"; fields: FormField[] }
  | { type: "list"; items: string[] }
  | { type: "image"; src: string; alt: string };

export function A2UIWidgetRenderer({ widget }: { widget: A2UIWidget }) {
  switch (widget.type) {
    case "card": return <Card title={widget.title}>{widget.content}</Card>;
    case "table": return <DataTable headers={widget.headers} rows={widget.rows} />;
    // ... other widget types
  }
}
```

### AG-UI Event Flow

```
RUN_STARTED (run_id)
    |
    v
STATE_SNAPSHOT (initial state)
    |
    v
STATE_DELTA* (incremental updates)
    |
    v
MESSAGES_SNAPSHOT (message history)
    |
    v
A2UI_WIDGETS (optional - generative UI)
    |
    v
RUN_FINISHED or RUN_ERROR
```
