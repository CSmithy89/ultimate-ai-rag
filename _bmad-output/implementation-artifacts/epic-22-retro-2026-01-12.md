## Challenges and Growth Areas

### 1. Route Collision in A2A Endpoints

**Challenge:** New middleware endpoints conflicted with existing `/a2a/agents/*` routes.

**Resolution:** Used `/a2a/middleware/` prefix to avoid collisions.

**Learning:** Plan API route namespacing during story refinement.

### 2. Complex Security Review Findings

**Challenge:** Story 22-A1 had multiple security issues:
- SSRF vulnerability in agent endpoint URLs
- Missing API key authentication
- Thread safety in HTTP client creation

**Resolution:** Comprehensive fixes including URL validation, asyncio.Lock for thread safety, and full API key verification.

**Learning:** Security-critical stories should have explicit security review checkpoints before implementation.

### 3. Prometheus Cardinality Concerns

**Challenge:** Event types and tenant IDs could cause metric cardinality explosion.

**Resolution:**
- Added `KNOWN_EVENT_TYPES` frozenset with normalization to "OTHER"
- Implemented tenant bucketing via `normalize_tenant_label()`

**Learning:** Always plan cardinality strategy for Prometheus labels upfront.

### 4. Gauge Underflow Edge Cases

**Challenge:** `ACTIVE_STREAMS` gauge could go negative if `stream_completed()` called without `stream_started()`.

**Resolution:** Added `_stream_started` flag with guard in `stream_completed()`.

**Learning:** Always consider edge cases for gauge metrics (inc/dec balance).

### 5. CopilotKit 2.x Dependency

**Challenge:** Story 22-TD6 blocked because CopilotKit 2.x is not yet stable (current: 1.50.1).

**Impact:** Cannot migrate from dual-format schemas (Zod + Parameter[]) yet.

**Recommendation:** Monitor CopilotKit releases; create reminder to unblock when 2.x is stable.

## Lessons Learned

### Key Insights

1. **Security-first mindset pays off:** Catching SSRF and auth issues in review prevents production vulnerabilities
2. **Protocol compliance tests are invaluable:** 157 tests now catch regressions early
3. **Tech debt tracking works:** 5/6 items from Epic 21 retro were addressed
4. **Code review thoroughness:** Multiple passes caught subtle issues (race conditions, cardinality)

### Patterns to Repeat

- Multi-pass adversarial code reviews for security-critical stories
- Protocol compliance test suites for each new protocol
- Grafana dashboard templates shipped with metrics
- Tech debt stories included in epic planning

### Patterns to Avoid

- Starting implementation without route namespace planning
- Prometheus metrics without cardinality strategy
- Gauge metrics without underflow protection
- Blocking stories on external dependencies (plan alternatives)
